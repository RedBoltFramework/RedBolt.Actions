# RedBolt.Actions

Optional composable time-based actions for [RedBolt](https://github.com/RedBoltFramework/RedBolt).

The source build expects RedBolt in `../RedBolt` by default. Override `RedBoltRoot` when the repositories use a different layout.

```sh
dotnet build RedBolt.Actions.slnx --configuration Debug
```

Desktop, WebAssembly, and Android versions of the Actions sample are included under `src/RedBolt/Sample`. Tests remain in the sibling `RedBolt.Tests` repository.
